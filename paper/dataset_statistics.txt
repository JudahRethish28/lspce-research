We generated 51 synthetic AWS CloudTrail JSON log files using the Faker library across three simulated tenants 
representing credential spray, insider exfiltration, and ransomware scenarios. Each file contains between 20 and 40 events seeded 
with realistic AWS resource identifiers, IAM usernames, IP addresses, and S3 ARNs. The dataset was manually annotated 
for personally identifiable information (PII) entities using a regex-assisted annotation workflow. 
Annotation quality was verified through repeated manual inspection across randomly sampled files. 
The final annotation corpus contains 10,500 labeled entities across four entity types: PERSON, IP_ADDRESS, AWS_ARN, 
and AWS_ACCOUNT_ID.
